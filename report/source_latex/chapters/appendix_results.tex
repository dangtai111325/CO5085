\section{Nguồn số liệu và hướng dẫn tái lập}
Số liệu lấy từ output E1.ipynb, E2.ipynb, E3.ipynb, A1.ipynb và
A2.ipynb trong source\_code. Manifest assets ghi notebook/cell/output;
report\_figures.json ghi các hình tĩnh dựng từ bảng/dữ liệu nguồn đã kiểm chứng.
Hình độc lập được ghép bằng LaTeX, không cắt từ raster ghép; TikZ theo code.
Mã kiểm chứng cách chia tập Fashion-MNIST/GTSRB được lưu tại
\texttt{assets/split\_identifiers.json} trong nguồn báo cáo.

E1--E3/A1: chuẩn bị dữ liệu theo README datasets, chọn Python 3.14 CUDA,
Restart Kernel/Run All/Save; các file độc lập. Patience/min-delta là
4/$10^{-4}$ cho E1--E3 và 2/$10^{-3}$ cho A1.
A2.ipynb dùng dataset \texttt{a2-voc2012} tại đường dẫn trong code,
accelerator T4 x2 và Internet khi cần weights/thư viện. Run All train hai
worker, rồi test/benchmark lần lượt; batch 8, accumulation 3, effective 24,
tối đa 30 epoch, patience 2/min-delta 0.001. Metadata ghi Python 3.13.15;
output không có phiên bản PyTorch/torchvision nên cần ghi môi trường khi tái lập.
Save notebook và tải \texttt{/kaggle/working/report/A2} cùng
\texttt{/kaggle/working/model/A2} trước khi kết thúc session.

Dùng CHECKPOINT\_ROOT trống để khởi tạo theo seed; latest.pt có sẵn thay đổi
weights đầu vào theo quy tắc Chương 1. Seed không bảo đảm bitwise qua GPU,
thư viện hay AMP. Số liệu A2 lấy từ output A2.ipynb chạy trên Kaggle,
theo protocol Chương~\ref{chap:a2}.

Báo cáo biên dịch bằng XeLaTeX và BibTeX từ report/source\_latex/main.tex;
TikZ định nghĩa trong architectures.tex, ảnh kết quả nằm ở assets.
PDF chung giữ tại report/CO5085\_Report.pdf.
