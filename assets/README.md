# Report assets

Tất cả hình ảnh được dùng trong báo cáo nằm ở thư mục này.

- `logos/`: logo/trang bìa.
- `shared/`: sơ đồ pipeline hoặc hình dùng chung.
- `e1/`, `e2/`, `e3/`: E1-E3.
- `a1/`, `a2/`: Assignment A1-A2.

Notebook chỉ được copy hình vào đây sau khi hình được sinh từ dữ liệu/thí nghiệm thật. Không commit dataset hoặc checkpoint lớn vào `assets/`.
